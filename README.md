# exitcode_py

Python constants for libc, LSB, BSD, and systemd exit codes, based on [this list compiled in the systemd docs](https://www.freedesktop.org/software/systemd/man/latest/systemd.exec.html#Process%20Exit%20Codes).

## Installation

This package is not published to PyPI; the name `exitcode` there belongs to an unrelated project. Install it from this repo:

```shell
pip install git+https://github.com/cdzombak/exitcode_py@v0.0.2
```

A wheel and sdist are also attached to each [GitHub release](https://github.com/cdzombak/exitcode_py/releases).

## Usage

```python
import sys

import exitcode

if len(sys.argv) < 2:
    sys.exit(exitcode.USAGE)
sys.exit(exitcode.SUCCESS)
```

## Generated code

`exitcode/__init__.py` is generated by [cdzombak/exitcodes](https://github.com/cdzombak/exitcodes) and should never be edited by hand. To change an exit code or add a new one, edit `exitcodes.tsv` in that repo; a pull request will be opened here automatically with the regenerated file.

Note that `pyproject.toml`'s version is *not* generated, and must be bumped to match before tagging a release; the release workflow checks this and fails if the two disagree.
